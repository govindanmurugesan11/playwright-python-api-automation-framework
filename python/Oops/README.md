# Object-Oriented Programming (OOP) in Python

This folder demonstrates the five fundamental OOP concepts in Python.

## Topics Covered

1. Class and Object
2. Inheritance
3. Polymorphism
4. Encapsulation
5. Abstraction

## Learning Path

Class → Object → Inheritance → Polymorphism → Encapsulation → Abstraction

## Run Example

```bash
python 1.class_object.py
```

## Why Learn OOP?

OOP concepts are heavily used in:

- Playwright Framework Development
- API Automation Frameworks
- Selenium Frameworks
- Robot Framework Custom Libraries
- Design Patterns
- Enterprise Software Development
